## 本地自动化结果

环境：

- macOS `26.5.1` aarch64
- Eclipse Temurin `25.0.3+9-LTS`
- Gradle `9.5.1`
- Fabric Loom `1.17.0-alpha.7`
- 构建 Fabric API `0.152.2+26.2`
- Carpet `26.2+v260616`

执行：

```shell
GRADLE_USER_HOME=/private/tmp/pearlrelay-gradle-home \
JAVA_HOME=/private/tmp/temurin-jdk25/Contents/Home \
GRADLE_OPTS='-Djava.net.preferIPv4Stack=true' \
./gradlew --no-daemon clean test build
```

结果：

- `BUILD SUCCESSFUL`
- JUnit：43/43 通过
- Fabric GameTest：15/15 通过
- GameTest 验证真实 Carpet 假人登录、命中音符盒一次、`note=0 -> 1`、
  唯一终态和假人清理。
- 最终生命周期回归验证：`start()` 只登记已接受任务；Carpet 假人创建从
  下一服务端 tick 开始，避免同步失败消息先于“已排队”消息。

测试框架启动时会先尝试读取临时目录中不存在的 `server.properties` 和
`eula.txt`，随后由 Fabric GameTest 正常接管并完成 15 项测试。这两条为
测试框架已知启动输出，不是候选包失败。创建测试假人时偶尔还会出现一次
`Can't keep up` 计时警告，但 15 项测试、唯一终态和清理断言仍全部通过。
Gradle 另报告了来自当前构建工具链的 Gradle 10 弃用提示，不影响本次
Gradle 9.5.1 构建。

最终候选远程烟测执行 ID：
`63019bf1-2b01-45cc-91ff-3a199f9c78e5`。该执行因首次使用全新假人名，
Carpet 的在线档案查询产生一次预期 `ProfileNotFound` 警告和约 2.4 秒延迟，
但仍在生成超时内成功完成。随后正常重启，最终 `latest.log` 无 WARN/ERROR、
无新崩溃报告、在线玩家为 0。

`DIMENSION_UNAVAILABLE` 由 Fabric GameTest 验证。由于保存目标必须位于
生存交互距离内，而目标珍珠的实体 tick 票据通常同时覆盖相邻出生区块，
隔离世界无法自然构造“目标可实体 tick、仅出生区块不可实体 tick”的有效
中继；`SPAWN_CHUNK_UNLOADED` 因此由不加载区块的单元测试覆盖。远程测试已
验证同一严格实体 tick 判定会拒绝卸载目标区块，且拒绝前后没有新增票据。
